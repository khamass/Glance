# Glance

Tagline: A little eye contact. A little personality.

Palette: midnight navy, warm gold, ivory, and teal. The eye, wink stroke, and sparkle evoke friendly camera awareness in a fantasy UI.

`icon.png` is the 512×512 plugin asset, copied into `images/` beside the built assembly. `glance-original.png` preserves the generated master.

Created with the built-in image generation tool. Final prompt:

> Use case: logo-brand. Create a final polished square icon for Glance, a fantasy RPG plugin that makes a character meet the camera's gaze and occasionally wink. One bold memorable emblem: an elegant luminous ivory and pale gold almond eye with a teal iris, paired with a small curved wink stroke and a single four-point gold sparkle. Midnight navy background, restrained luminous edge highlights, tasteful premium fantasy UI enamel medallion feel, sophisticated playful personality. Strong silhouette, centered generous safe margins, extremely legible at 64 pixels, minimal detail. Flat front-facing graphic, not a scene or mockup. No letters, no text, no watermark, no game logos. Square 1024x1024 artwork.

The generated master was proportionally resized to the required 512×512 plugin icon using high-quality bicubic resampling.
